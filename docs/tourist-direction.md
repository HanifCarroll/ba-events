# Tourist / Short-Term Visitors Product Direction

North Star
- Help a visitor answer: “What should I do tonight (or this weekend), near me, within my budget?” in under 30 seconds.

Core product shifts (tourist lens)
- Speed > depth: default to 3–5 high-confidence picks, not long lists.
- Decision support: emphasize time, neighborhood, price, and “why it’s good for visitors.”
- Trust cues: show source verified + last updated + tickets available.

Recommendations (prioritized)

1) Make events shareable and indexable
- Add /event/:id pages with OG tags, canonical URL, and a clean summary.
- Include “Open in Maps,” “Get Tickets,” and “Share” buttons.
- Enables SEO + social sharing (tourists send links to friends).

2) One‑tap “Tonight / This Weekend / Near Me”
- Add a quick-start panel above chat: Tonight, This weekend, Near me, Free, Top picks.
- Use geolocation or user-selected neighborhood; default to Palermo/Recoleta/San Telmo.

3) Add “Tourist mode” preferences
- 2-step onboarding: timeframe + budget + vibes + neighborhoods.
- Store and apply as default filters (visible chips to edit).

4) Trust + clarity on every result
- Show source badge (Passline/Eventbrite/BA Tourism/Meetup).
- Show last updated and language (ES/EN).
- Show “Limited info” warning if description is missing.

5) Decision accelerators
- “Good for tourists” highlight (AI-generated or rule-based).
- Short “what to expect” sentence on event cards (from description).
- Travel-friendly tags (walkable, indoor, family-friendly, English-friendly).

6) Tourist-friendly actions
- Add “Add to Calendar” (ICS) and “Open in Maps.”
- Add “Plan my night” – a 2–3 stop itinerary from chat results.

7) Monetization-ready hooks (non-intrusive)
- Affiliate links for ticketed events.
- Featured picks (“sponsored”) with clear label.
- Hotel/hostel concierge widgets (embed a mini search).

30–60–90 roadmap

Next 30 days (quick wins)
- /event/:id pages + OG tags
- “Tonight / Weekend / Near me” quick buttons
- “Add to Calendar” + “Open in Maps”
- Source badges + last updated labels

Next 60 days (retention & conversion)
- Tourist onboarding (timeframe, budget, vibes, neighborhoods)
- “Tourist mode” chip filters visible in chat UI
- “Good for tourists” tag and short event summaries
- Email/WhatsApp “Your weekend picks” digest

Next 90 days (growth + revenue)
- Lightweight itinerary builder (“Plan my night”)
- Affiliate tracking + sponsored placements
- Partner distribution (hotels/hostels/airbnbs)
